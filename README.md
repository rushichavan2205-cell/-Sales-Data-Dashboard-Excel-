## 📊 Sales Data Dashboard using Excel

## 📌 Overview

This is an interactive Sales Data Dashboard built entirely in Microsoft Excel. It helps analyze sales performance across regions, product categories, shipping modes, and customer segments using PivotTables, PivotCharts, and Slicers.

## 🔑 Key Metrics
Metric	Value

💰 Total Sales	2,297,201

📈 Average Sales	230

🧾 Total Transactions	9,994

📦 Total Quantity Sold	37,873

## 📈 Dashboard Features

🎛️ Region & Category Slicers	Filter the whole dashboard by Region (Central, East, South, West) and Category (Furniture, Office Supplies, Technology).

🥧 Ship Mode-wise Sales	Sales distribution across First Class, Same Day, Second Class, Standard Class.

🥧 Zone-wise Sales	Sales breakdown by region.

📉 Monthly Sales Trend	Sales quantity trend across all 12 months.

🏙️ Top 5 Selling Cities	Top-performing cities (New York City, Los Angeles, Seattle, etc.).

📊 Count of Category by Ship Mode	Comparison across shipping modes.

📊 Segment-wise Quantity	Quantity sold across Consumer, Corporate, Home Office segments.

## 🛠️ Tools & Techniques
Used
Microsoft Excel
PivotTables & PivotCharts
Slicers for interactive filtering
Dashboard design & formatting

## 🎯 Purpose

Built to practice data visualization and dashboard design skills in Excel, simulating a real-world retail sales analysis scenario.
